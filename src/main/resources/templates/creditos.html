Backend con servicios RESTful CRUD sobre una entidad Producto, construido con Spring Boot y Kotlin bajo arquitectura hexagonal, con ORM sobre PostgreSQL. El mismo nucleo se expone por dos adaptadores de entrada: la API REST y esta interfaz web.

El sistema de diseno de esta interfaz toma los patrones visuales de las aplicaciones de streaming musical (base oscura, verde de acento, controles en pildora, rejilla de tarjetas). No emplea marcas, logotipos ni tipografias propietarias de terceros.
